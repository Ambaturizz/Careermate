# @careermate/contracts

Package ini adalah satu-satunya sumber schema request/response CareerMate. Backend memvalidasi input dan output model dengan schema yang sama; frontend memvalidasi response API sebelum digunakan.

Jangan menyalin interface dari package ini ke frontend atau backend. Jika repository dipisah, publikasikan package ini dengan semantic versioning ke GitHub Packages, atau migrasikan schema menjadi OpenAPI yang dihasilkan oleh backend.
